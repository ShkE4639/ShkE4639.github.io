# Jump Climb(プロトタイプ)

落下中にタップして、空中ジャンプをつないで上へ登る、スマホ向けの小さなブラウザゲームの試作です。

## 遊び方
- タップでスタート。
- キャラが落下に入ったら、もう一度タップするとジャンプします。
- **キャラの真下をタップ**すると、真上へ大ジャンプします。
- **キャラの左下をタップ**すると右上へ、**右下をタップ**すると左上へ、斜めに跳びます(横に進む代わりに低くなります)。
- 緑色のとき、タップが有効です。橙色のときは無効です(上昇中)。
- 画面の左右の端は壁です。壁に当たると横に進めなくなります。
- 一番上のゴールラインまで登るとクリアです。タイムを縮めましょう。
- 右上の「⚙ 調整」で、ジャンプの高さなどを変えられます。

PCでは、スペースキー=真下のタップ、←→(またはA/D)=跳びたい方向になります。

## ファイル構成

```
index.html        画面の骨組み
style.css         見た目
src/
  config.js       調整できる値とヒント
  sim.js          ゲームの計算(描画なし・時刻なし)
  input.js        タップをキューに貯める
  recorder.js     入力ログの記録
  render.js       描画
  panel.js        調整パネル
  storage.js      localStorage の読み書き
  main.js         全体をつなぐ。固定タイムステップのループ
test/sim.test.mjs sim の自動テスト
```

## ローカルで動かす

ES Modules を使っているので、`index.html` を直接開くのではなく、簡易サーバーを使います。

```
npx serve
```

表示されたアドレスをブラウザで開いてください。

## テスト

```
node test/sim.test.mjs
```

## 調整のヒント

| 感じたこと | 試すこと |
|---|---|
| もっさり重い | 頂点までの時間を下げる / 落下の重さを上げる |
| ふわふわで頼りない | 落下の重さを 1.3〜1.5 に |
| 登っても進んだ気がしない | ジャンプの高さを上げる |
| 連打で指が疲れる | 高さを上げる / 頂点までの時間を上げる |
| 押したのに跳ばない気がする | 先行入力の猶予を上げる |
| 真下を狙ったのに斜めになる | 真下の判定幅(不感帯)を広げる |
| 斜めが出しにくい | 不感帯を狭める / 最大斜めの位置を近づける |
| 斜めが速すぎて壁にぶつかる | 斜めの横速度を下げる |
| 斜めにしても損がなくて単調 | 斜めで低くなる割合を上げる |
| 判定が見えて邪魔 | 判定ゾーンの表示をOFFにする |

1回に1つだけ変えて、5回遊んでから判断するのがおすすめです。

## 再現性のルール(sim.js を触るときの約束)
1. 時間はステップ数だけで進める(`Date.now()` や `performance.now()` を使わない)
2. 乱数は使わない(使うなら seed つき)
3. 四則演算だけ使う(`Math.sin` などは端末差が出うる)
4. 入力は `step()` の引数で渡す

## 保存されるデータ
調整値、ベストタイム、直前の入力ログは、ブラウザの `localStorage` に保存されます。外部には送信されません。

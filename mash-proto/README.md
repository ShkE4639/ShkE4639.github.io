# 連打プロトタイプ ステップ2「技を切り替えて、コンボを作る」

画面下のボタン(弱・中・強・必殺)で技を選び、**画面をタップ**して敵(正面に映る上半身)を殴る。視点は画面越しに敵を見ている一人称で、自分の体は映らない(殴るときだけ画面の下から腕が伸びる)。右端の「溜撃」ボタンは、後ろで溜めて撃つ大技。
目的は **「技を切り替えながら殴るのが気持ちいいか・面白いか」を確かめること**。ゲームとしてはまだ何もない。

## 遊び方

**画面下のボタン = 技を選ぶだけ(押しても攻撃は出ない)。画面のどこかをタップ = 選んでいる技で攻撃。**
選んでいる技のボタンは、明るく白い枠が付いて少し持ち上がる。

| 技 | 画面での操作 | 特徴 |
|---|---|---|
| 弱 | タップ | 軽く速い。連打向き |
| 中 | タップ | 標準 |
| 強 | タップ | 重い。揺れ・ヒットストップ・のけぞりが大きく、音が低い |
| 必殺 | **画面を長押しして溜め、離す** | 溜めるほど威力が上がる(溜め中は画面の下に拳が現れて大きくなる)。満タンで「ピッ」と鳴り、離すと画面が光る |

- 片手で画面を連打しながら、もう片方の親指でボタンを切り替える、という使い方を想定している
- 溜めている最中は、技を切り替えられない
- 拳・衝撃の輪・擬音の文字・火花・ダメージ数字は、すべて**タップした場所**に出る(必殺は指を離した場所)。キーボード操作のときだけ、敵の位置に出る
- 画面左上に、今のコンボで出した技の並び(例: 弱 弱 中 強)が出る
- PCで試すときは、キーボードの **1 2 3 4** で技を選び、**スペースキー**で攻撃(必殺はスペースを押している間溜まる)、**5** で溜撃

### 溜撃(後ろで溜めて、光ったら撃つ大技)

右端の「溜撃」ボタンは、技を選ぶボタンではなく**押す専用**のボタン。

1. **押す** → 後ろで溜まり始める(ボタンが下から色で満ちていく。画面の縁も色づいていく)
2. **溜まっている間も、選んでいる技で普通に殴れる**(技の切り替えもできる)
3. **満タンになるとボタンが光って脈打つ**(音と振動の合図も出る)
4. **光っている間にもう一度押す** → 発射。画面がピカッと光る
   - 光る前に押しても何も起きない。光ったあとは、押すまでそのまま待っていられる(撃つタイミングは自分で決める)
   - 撃ったあとは、もう一度押せばまた溜まり始める

## ファイル構成(役割ごとに分けてある)

| ファイル | 役割 | 触るのはどんなとき |
|---|---|---|
| `index.html` | 画面の枠・見た目(ボタンや⚙パネルのデザイン)・読み込むファイルの一覧 | 基本触らない |
| `js/config.js` | **技の一覧と、調整できる数値がすべてここ** | 手触りを変えたいとき・技を足すとき(最頻出) |
| `js/audio.js` | 効果音(その場で合成。音声ファイル不要) | 音の質を変えたいとき |
| `js/effects.js` | 画面揺れ・ヒットストップ・ズーム・火花・拳・衝撃の輪・擬音・数字・画面フラッシュ | 演出の種類を増やしたいとき |
| `js/game.js` | 敵(上半身)、**技が出たときの処理(attack)**、溜め、描画 | ゲームのルールを増やすとき |
| `js/input.js` | 技ボタンの作成と、画面タップ・長押し・溜撃ボタンの受け取り | 入力方法を変えるとき(スワイプ追加など) |
| `js/tuner.js` | ⚙の調整パネル | 基本触らない |
| `js/main.js` | 起動とループ(各ファイルをつなぐだけ) | 基本触らない |

**「技が出たら何が起きるか」を知りたければ `game.js` の `attack()` を読む。**
演出を1つずつ呼んでいるだけなので、行を消せばその演出が消える(試しにコメントアウトすると、各演出の効果がよくわかる)。

## 調整のしかた

⚙ を押すとパネルが開く。**パネルを開いたまま、画面をタップして試せる。**
画面下の技ボタンを押すと、パネルも自動でその技のタブに切り替わる。

1. **技のタブを選ぶ**(弱 / 中 / 強 / 必殺 / 溜撃。「共通」はコンボ関係)
2. **「迫力」スライダーを動かす** … 揺れ・ヒットストップ・のけぞり・火花・拳・衝撃・擬音の大きさが、まとめて強く/弱くなる。**まずはこれだけでよい**
3. それでも足りないときだけ「細かい調整を開く」で、1項目ずつ動かす(1回に1項目だけ動かすと、何が効いたかがわかる)

### パンチらしさ・派手さの演出

当たるたびに、次の演出が重なって出る。それぞれ「細かい調整」の「見た目の演出」で大きさを変えられ、**0にするとその演出だけ消える**(何が効いているか確かめるのに使える)。

| 演出 | 何が出るか | 調整項目 |
|---|---|---|
| 拳 | 画面の下の左右の縁から、タップした場所まで腕と拳が伸びる(タップした側に近い腕を使い、中央付近は左右交互)。当たった瞬間の姿で一瞬止まり、戻る | 拳の大きさ |
| 衝撃 | タップした場所に、輪と放射線が広がる | 衝撃の大きさ |
| 擬音 | 「ペシッ」「ドスッ」「ドガッ!」などの文字が、少し傾いて出る(技ごとに候補があり、ランダム) | 擬音の文字の大きさ |
| 敵の反応 | 殴られた側と反対へずれて傾き、少し潰れ、奥へ下がる。のけぞりの大きい技ほど大きく動く | (「のけぞり」に連動) |
| ズームパンチ | 当たった瞬間、画面がわずかに拡大して戻る | ズームパンチ |
| 火花 | 飛んでいく向きに伸びる筋 | 火花の数・勢い |

擬音の文字は、`js/config.js` の `MOVE_INFO` の `sfx` で書き換えられる(技ごとに複数書ける)。

### 技ごとの狙い(初期値の考え方)

| 技 | 狙い | 揺れ | ヒットストップ | 音 | 見た目 |
|---|---|---|---|---|---|
| 弱 | テンポよく軽く | 小 | 短い | 高く短い | 小さな拳・小さな衝撃 |
| 中 | 標準 | 中 | 中 | 標準 | 中くらいの拳・わずかなズーム |
| 強 | ズシッと重い一撃 | 大 | 長い | 低く長い | 大きな拳と大きな擬音・ズーム |
| 必殺 | 溜めの末のカタルシス | 特大 | 長い | 低く長い | とても大きな拳と衝撃 |
| 溜撃 | 狙ったタイミングで入れる最大の一撃 | 最大 | 最長 | 最も低く長い | 最大の衝撃と擬音(画面に収まるよう自動で縮む) |

**この初期値は、私の予想で決めた仮の値。実際に触って、違うと思ったところが調整の出発点。**
「強が弱と変わらない」「必殺が地味」などは、その技のタブで「迫力」を上げる。

### 症状 → 触る場所

| こう感じる | まず触る項目 | 方向 |
|---|---|---|
| どの技も同じに感じる | 技のタブごとの「音の高さ」「ヒットストップ」の差 | 差を広げる |
| その技が軽い・スカスカ | その技の「迫力」 | 上げる |
| 重すぎる・もたつく | その技の「ヒットストップ」 | 下げる(連打すると動きがカクカクして見える) |
| 画面が揺れすぎて見づらい・酔う | その技の「画面揺れの強さ」 | 下げる |
| 当たった感じが薄い | 「敵の白点滅」「のけぞり」 | 上げる |
| 地味 | 「火花の数」「火花の勢い」「衝撃の大きさ」 | 上げる |
| パンチに見えない | 「拳の大きさ」 | 上げる(0にすると拳が消えるので、効き具合も確かめられる) |
| 擬音がうるさい・見づらい | 「擬音の文字の大きさ」 | 下げる(0で消える) |
| 重さが伝わらない | 「ズームパンチ」「ヒットストップ」 | 上げる(ズームは上げすぎると酔いやすい) |
| 音が単調 | 共通タブの「コンボごとの音の上がり」 | 上げる(0.5前後) |
| 音が高くなりすぎて耳に痛い | 共通タブの「音の上がり上限」 | 下げる |
| コンボがすぐ切れる / 切れない | 共通タブの「コンボが切れるまで」 | 調整 |
| 必殺を溜めるのが待ち遠しい / すぐ撃ててしまう | 必殺の「満タンまでの溜め時間」 | 短く / 長く |
| 必殺を溜める意味がない | 必殺の「溜めずに離したときの威力」 | 下げる |
| 溜撃が光るまで長い / 短い | 溜撃の「満タンまでの時間」 | 短く / 長く(初期値は3秒) |

**「硬直」について**: 技を出したあと次の技を出せるまでの時間。今は全部0(制限なし)。
フィニッシュタイムは自由に殴れる方針なので、迷ったら0のままでよい。

### 気に入った設定を残す・送る

- ⚙パネル下の **「設定を書き出す」** を押すと、全技の今の設定が文字で出る(自動でコピーされる)。チャットにそのまま貼れば、その値を初期値に取り込める
- 自分で `config.js` に書き写すときは、`MOVE_DEFAULTS` の該当する数字を書き換える

### ⚠ 初期値を変えたのに反映されないとき

⚙で動かした値は、**そのスマホの中に保存される**。ただし保存されるのは「**動かして、初期値と違う値になった項目だけ**」。
そのため、`js/config.js` の初期値を書き換えてpushすると、**触っていない項目には新しい初期値が反映される**。一度でも動かした項目だけは、保存済みの値が優先されて変わらない。
その項目も新しい初期値にしたいときは、⚙パネル下の **「この技を初期値に戻す」** か **「全部を初期値に戻す」** を押す。

なお、今回の版で保存の形式を変えたため、**以前の版で保存した値は引き継がれない**(初期値から始まる)。

## 新しい技を足す

`js/config.js` に2か所足すだけ。ボタンも⚙のタブも自動で増える。

1. `MOVE_INFO` に1行足す(id・名前・色・ダメージ数字・数字の大きさ・擬音の候補)
2. `MOVE_DEFAULTS` に、同じidで初期値を足す(既存の技をコピーして数字を変えるのが早い)

技の種類は `MOVE_INFO` で決まる。何も付けなければ「選んで、画面タップで出す技」、`charge: true` を付けると「画面の長押しで溜める技」、`delayed: true` を付けると「押す専用ボタンで、後ろで溜めて撃つ技」になる(溜撃がこれ)。

## Androidで動かす

### A. GitHub Pagesで公開する(おすすめ)

1. GitHubで新しいリポジトリを作る(**GitHub Freeプランでは Public が必須**)
2. このフォルダの**中身**(`index.html`、`js/`、`README.md`、`.nojekyll`)をリポジトリの**一番上の階層**に置いてpushする
   - ⚠ `mash-proto` フォルダごと置くと `index.html` が1階層下になり、公開しても表示されない(404になる)
3. リポジトリの **Settings → Pages → Build and deployment** で、Source を **Deploy from a branch** にし、Branch は `main`、フォルダは `/ (root)` を選んで **Save**
4. 数分〜最大10分ほど待つと、次のURLで開ける(スマホのChromeでこのURLを開くだけ)

   `https://<ユーザー名>.github.io/<リポジトリ名>/`

**更新するとき**: 新しいファイルで、同じ名前のファイルを上書きしてpushする(`index.html`、`README.md`、`js/` の中身)。Pagesは自動で更新される。

**公開について知っておくこと**

- Publicリポジトリなので、**ソースコードもURLも誰でも見られる**。今回のコードに個人情報や鍵は入っていないが、今後ファイルを足すときは公開されてもよいものだけを置く
- 他人がコードを再利用してよいかは、リポジトリに `LICENSE` を置いて決める(置かない場合、閲覧はできるが再利用の許可は明示されない)
- 検索結果に載りにくくする設定(`noindex`)は入れてあるが、URLを知っていれば誰でも開ける

**更新したのにスマホで変わらないとき**

- 反映まで最大10分かかる。pushした直後は古いままのことがある
- ブラウザが古いファイルを覚えていることもある。Chromeのメニューから再読み込みするか、URLの末尾に `?v=2` のように付けて開き直す(数字を変えるたびに新しいものを読む)

### B. ローカルで試す(公開しない)

- **PCと同じWi-Fi**: PCで、このフォルダを開いた状態で `python3 -m http.server 8000` を実行。スマホのChromeで `http://<PCのIPアドレス>:8000` を開く
- **端末に直接コピー**: フォルダごとスマホに入れ、ファイルマネージャーから `index.html` をChromeで開く(環境によっては調整値の保存が効かないことがある)

## 判断ポイント②(このステップのゴール)

しばらく自由に殴ってみて、次を自分に聞く。

- **技を切り替えたくなったか**。それとも、気に入った1つのボタンだけを連打していたか
- 技ごとの「違い」を、手と耳で感じられたか(感じにくければ、数値の差をもっと広げる)
- 必殺の「溜めて離す」は、気持ちよい山場になっているか
- 4種類を組み合わせて、「自分のコンボ」を作る気になったか

**1つのボタンだけを連打してしまう場合**は、硬直を入れるのではなく、まず「技ごとの違い」をもっとはっきりさせる(迫力・音の高さ・音の長さの差を広げる、斬撃のような見た目の違う技を足す等)。
それでも切り替えたくならないなら、「技の切り替え」自体が面白さの中心ではない、という大事な発見になる。その場合は、方向を考え直す。

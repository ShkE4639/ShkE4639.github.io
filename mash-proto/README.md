# 連打プロトタイプ ステップ1「連打の手触りだけ確かめる」

敵(四角)に向かって画面のどこでもタップ連打する。
目的は **「連打が気持ちいいか」だけを確かめること**。ゲームとしてはまだ何もない。

## ファイル構成(役割ごとに分けてある)

| ファイル | 役割 | 触るのはどんなとき |
|---|---|---|
| `index.html` | 画面の枠と、読み込むファイルの一覧 | 基本触らない |
| `js/config.js` | **調整できる数値がすべてここ** | 手触りを変えたいとき(最頻出) |
| `js/audio.js` | 効果音(その場で合成。音声ファイル不要) | 音の質を変えたいとき |
| `js/effects.js` | 画面揺れ・ヒットストップ・火花・数字 | 演出の種類を増やしたいとき |
| `js/game.js` | 敵とプレイヤー、**タップ時の処理(hit)**、描画 | ゲームのルールを増やすとき |
| `js/input.js` | タップの受け取り | 入力方法を変えるとき(スワイプ追加など) |
| `js/tuner.js` | ⚙の調整パネル | 基本触らない |
| `js/main.js` | 起動とループ(各ファイルをつなぐだけ) | 基本触らない |

**「タップしたら何が起きるか」を知りたければ `game.js` の `hit()` を読む。**
演出を1つずつ呼んでいるだけなので、行を消せばその演出が消える(試しにコメントアウトすると、各演出の効果がよくわかる)。

## Androidで動かす

### A. GitHub Pagesで公開する(おすすめ)

1. GitHubで新しいリポジトリを作る(**GitHub Freeプランでは Public が必須**)
2. このフォルダの**中身**(`index.html`、`js/`、`README.md`)をリポジトリの**一番上の階層**に置いてpushする
   - ⚠ `mash-proto` フォルダごと置くと `index.html` が1階層下になり、公開しても表示されない(404になる)
3. リポジトリの **Settings → Pages → Build and deployment** で、Source を **Deploy from a branch** にし、Branch は `main`、フォルダは `/ (root)` を選んで **Save**
4. 数分〜最大10分ほど待つと、次のURLで開ける(スマホのChromeでこのURLを開くだけ)

   `https://<ユーザー名>.github.io/<リポジトリ名>/`

**公開について知っておくこと**

- Publicリポジトリなので、**ソースコードもURLも誰でも見られる**。今回のコードに個人情報や鍵は入っていないが、今後ファイルを足すときは公開されてもよいものだけを置く
- 他人がコードを再利用してよいかは、リポジトリに `LICENSE` を置いて決める(置かない場合、閲覧はできるが再利用の許可は明示されない)
- 検索結果に載りにくくする設定(`noindex`)は入れてあるが、URLを知っていれば誰でも開ける

**更新したのにスマホで変わらないとき**

- 反映まで最大10分かかる。pushした直後は古いままのことがある
- ブラウザが古いファイルを覚えていることもある。Chromeのメニューから再読み込みするか、URLの末尾に `?v=2` のように付けて開き直す(数字を変えるたびに新しいものを読む)

### B. ローカルで試す(公開しない)

- **PCと同じWi-Fi**: PCで、このフォルダを開いた状態で `python3 -m http.server 8000` を実行。スマホのChromeで `http://<PCのIPアドレス>:8000` を開く
- **端末に直接コピー**: フォルダごとスマホに入れ、ファイルマネージャーから `index.html` をChromeで開く(環境によっては調整値の保存が効かないことがある)

## 調整ガイド(症状 → 触る場所)

⚙ を押すとパネルが開く。**パネルを開いたまま、画面の上半分を連打して確かめられる。**
1回に1項目だけ動かすと、何が効いたかがわかる。

| こう感じる | まず触る項目 | 方向 |
|---|---|---|
| 軽い・スカスカする | ヒットストップ / 揺れの強さ | 上げる |
| 重すぎる・もたつく | ヒットストップ | 下げる(40以下に) |
| 連打するとカクカクして見える | ヒットストップ | 下げる |
| 画面が揺れすぎて見づらい・酔う | 揺れの強さ / 揺れの収まる速さ | 強さを下げる、収まりを小さく |
| 当たった感じが薄い | 敵の白点滅 / のけぞり | 上げる |
| 地味 | 火花の数 / 火花の勢い | 上げる |
| 音が単調 | コンボごとの音の上がり | 上げる(0.5前後) |
| 音が高くなりすぎて耳に痛い | 音の上がり上限 | 下げる |
| 連打が途切れるとすぐ切れる / 切れない | コンボが切れるまで | 調整 |
| 指に伝わる感じがほしい / 鬱陶しい | 振動 | 上げる / 0にする |

### ⚠ 初期値を変えたのに反映されないとき

⚙で動かした値は、**そのスマホの中に保存される**。そのため `js/config.js` の初期値(`value:`)を書き換えてpushしても、保存済みの値が優先されて変わらない。
新しい初期値を試したいときは、⚙パネル上部の **「全部を初期値に戻す」** を押す。

おすすめの流れ: ⚙でいろいろ動かして気に入った値をメモ → `config.js` の `value:` に書き写す → 「全部を初期値に戻す」で確認。

## 判断ポイント①(このステップのゴール)

30秒間、思いきり連打して、次を自分に聞く。

- 途中で飽きなかったか
- 設定を触ると、はっきり気持ちよさが変わる項目があったか
- 「これ以上は演出を足さないと無理」と感じたか

飽きた場合は、連打そのもの(長押しで溜める、スワイプの方向で変える等)に変化を付ける必要がある、という重要な発見になる。
その場合は、カウンター部分を作る前に方向を考え直す。
